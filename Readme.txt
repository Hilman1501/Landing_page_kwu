# Landing Page KWU

Landing page sederhana untuk keperluan latihan desain web statis.  
Dibuat menggunakan HTML, CSS, dan JavaScript dasar.

---

## 📌 Deskripsi

Project ini adalah landing page untuk mendemonstrasikan:
- Struktur HTML yang rapi dan semantik
- Desain responsif menggunakan CSS
- Interaksi dasar dengan JavaScript 

## ⚙️ Teknologi yang Digunakan

- **HTML5**
- **CSS3**
- **JavaScript **

## 💡 Tujuan Pembuatan

Project ini dibuat untuk:
- Melatih kemampuan membuat layout landing page modern
- Memahami struktur elemen HTML & penataan CSS
- Membuat website yang mobile-friendly dan responsif
- Mendokumentasikan hasil belajar di GitHub
